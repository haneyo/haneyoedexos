# eDEX-OS 交接文档 — 2026-08-25

> 目的:记录「主题/背景系统性翻新 + 自定义背景来源」这轮改动与部署状态,便于下一个会话/构建续接。当前仓库将发布 **v2.4.27**。

## 本轮核心内容(源码改动,已在此提交)

### 1. 新增「桌面背景来源」设置(backgroundMode)
- 设置 → 通用 → **背景图片**:四档模式按钮(**主题默认 / 点阵 / 等高线·军事地图 / 自定义图片**),eDEX 风格、可键盘操作。
- 主进程新增 `ipc.handle("settings:pickImage")`(原生图片对话框);`settings.backgroundMode` + `settings.backgroundImage` 持久化,启动时 `applyBackground()` 自动应用。
- 逻辑在 `src/_renderer.js`(`applyBackground`/`bgSetMode`/`bgPick`/`bgClear`,`window.BG_CONTOUR` = 终末地军事图数据 URI);默认值在 `src/_boot.js`。

### 2. 三个主题的背景全面翻新(均以自包含数据 URI 存进 `injectCSS`,可热更到真机)
- **终末地 endfield**:野外/山地勘测图,改为**多色暖调**(信号黄等高线 + 奶油信息 + 琥珀建筑 + 陶土设施 + 卡其三角位)。
- **战地 battlefield(已从 battlefield4 改名)**:改用**真实城市路网**(OpenStreetMap 成都主干道 + 河流)作底,叠**虚构军事元素**(AB-01 空军基地 / AMMO-1·2 弹药库 / FOB-B1·C2 前进基地 / FUEL-1 燃料 / RADAR-1 雷达 / HQ / LZ-1 停机坪 / SUP-1 / OBS-1),去掉所有真实地名;战地配色「橙 + 蓝青」。
- **星穹铁道 star-rail**:背景为**真实全天星图**(d3-celestial 6 等星表 + 真实星座连线,按成都/天顶投影),已去掉「Chengdu」「日期时刻/经纬度/天顶坐标」等标注文字;配色金 + 深靛蓝 + 薰衣草。

### 3. 主题配置
- `endfield.json`/`endfield-focus.json`(多色野图)、`battlefield.json`/`battlefield-focus.json`(真实城市军用图)、`star-rail.json`/`star-rail-focus.json`(真实星图)。
- 每个主题附加 `injectCSS`:body 背景 + 激活 tab 强调色(终末地黄 / 战地橙 / 星穹金)。
