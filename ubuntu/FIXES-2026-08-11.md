## 一句话

真机系统 = `src/`(基础源码)→ 构建 AppImage → `patch-appimage.sh` 打 12 处补丁 → **12fix**。

## 如何重建 12fix(异地)

```bash
# 1. 取上游 v2.3.11 AppImage(或 Release 里任意基础版)
# 2. 打补丁:
bash packaging/patch-appimage.sh  eDEX-UI.AppImage  eDEX-UI.AppImage.12fix
#    (脚本幂等:已打过补丁的输入会原样跳过)
# 3. 语法自检(脚本内置):7 个 patch 文件 node --check 全过 = 可以部署
# 4. 部署(真机 /opt/edex):
#    sudo systemctl stop lightdm && sudo pkill -f eDEX-UI.AppImage || true
#    sudo cp eDEX-UI.AppImage.12fix /opt/edex/eDEX-UI.AppImage && sudo chmod 755 /opt/edex/eDEX-UI.AppImage
#    sudo systemctl start lightdm
```

> ETXTBSY:运行中的 AppImage 不能被 `cp -f` 覆盖,必须先停 lightdm(或 `rm + cp`)。

## ⚠️ 2026-08-11 事故记录(必读纪律)

- **事故**:补丁 12 的 `RESET_JS` 曾注入 `locationGlobe.class.js` 的 **class 类体内**
  → 类体不允许 `const` 声明 / IIFE → `SyntaxError: Unexpected identifier`
  → renderer 崩溃 → **UI 无法启动**。
- **修复**:改为**模块级 IIFE**,注入文件尾 `module.exports={LocationGlobe};` 之后。
- **纪律**:任何注入点必须 `node --check` 通过后再部署;**类体内禁 `const` / IIFE**。
